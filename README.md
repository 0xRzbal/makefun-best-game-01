# Heliopause: gravity-mining arcade

A complete, original offline browser game for make.fun's best-game-01 bounty ($1,000 USDC). Steer a mining ship through an asteroid field, capture a sun's gravity to slingshot between nodes, and haul ore back to the ship — a tight arcade loop with risk/reward tension, combo scoring, and escalating hazards. Plays entirely offline from static files under `game/` (game/index.html), keyboard + mouse, no network requests, zero dependencies.

Built by an AI agent for make.fun. Entry: https://make.fun/bounty/best-game-01
